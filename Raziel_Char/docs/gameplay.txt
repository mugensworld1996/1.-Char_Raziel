# Controles básicos

## Layout estándar MUGEN

```txt
x  y  z
a  b  c
      s
```

| Botón | Acción |
|---|---|
| x | Golpe débil |
| y | Golpe medio |
| z | Golpe fuerte |
| a | Patada débil |
| b | Patada media |
| c | Patada fuerte |
| s | Taunt |

---

|---|---|
| Caminar | ← / → |
| Saltar | ↑ |
| Dash adelante | → → |
| Dash atrás | ← ← |
| Air Jump | En el aire + ↑ |

# Sistema Soul Reaver

El Soul Reaver es un sistema visual persistente implementado mediante overlays y palettes independientes.

Actualmente:

- Se muestra en idle
- Walk
- Crouch
- Transiciones de crouch

Cada palette puede utilizar una variante distinta del Reaver.

---

# Instalación

1. Copiar `Raziel_Char/` dentro de `chars/`
2. Abrir `data/select.def`
3. Agregar:

```txt
Raziel_Char/raziel
```

4. Iniciar MUGEN y seleccionar el personaje.
