# Raziel — Legacy of Kain | MUGEN Project

## Sobre este proyecto

Este proyecto busca recrear a **Raziel**, protagonista de la saga **Legacy of Kain: Soul Reaver**, como un personaje jugable para **MUGEN**.

La versión actual representa a **Raziel en su forma espectral (Azul)**, incluyendo el sistema visual del **Soul Reaver**, variantes de paleta y animaciones completamente nuevas creadas específicamente para este proyecto.

Actualmente el personaje se encuentra en una etapa temprana de desarrollo.

## Filosofía del proyecto

Este proyecto sigue la filosofía clásica de la comunidad MUGEN:

> MUGEN es de la comunidad para la comunidad.

Todo el contenido aquí presente es completamente libre:

- Libre para usar
- Libre para modificar
- Libre para estudiar
- Libre para redistribuir

No existen:
- Paywalls
- Bloqueos
- Monetización
- Restricciones comunitarias

El objetivo es compartir conocimiento, recursos y contenido con la comunidad.

## Desarrollo del personaje

Los sprites de este personaje están siendo creados desde cero utilizando distintas herramientas de IA y procesos manuales de edición.

### Pipeline de desarrollo

1. Creación de sprites base.
2. Conversión a estilo 3D.
3. Generación de animaciones.
4. Conversión a video.
5. Extracción de frames.
6. Edición y limpieza manual.
7. Conversión final a BMP para MUGEN.
8. Importación al SFF.
9. Creación de AIR, CLSN y lógica MUGEN.

### Herramientas utilizadas

- ChatGPT
- Grok
- Gemini
- A2E
- Vidu
- VLC
- Fighter Factory Clasic
- Herramientas de edición de imagen, BMP y palettes ACT

## Base del proyecto

El proyecto parte de la plantilla clásica de MUGEN / Elecbyte y también ha estudiado implementaciones anteriores de Raziel realizadas por otros autores.

Referencias históricas utilizadas durante el desarrollo:

- Raziel Seylos
- Dave Rattlz

Su trabajo sirvió como base inicial para estados, movimientos y lógica general del personaje.
El personaje de Dave Rattlz se utiliza principalmente como **referencia de estudio** para ideas sobre Reavers, Helpers, states y organización de lógica. La arquitectura actual de este proyecto se está desarrollando de forma independiente y fue reorganizada para soportar dos formas principales: con espada física y sin espada.

A partir de esa base se están desarrollando:

- Nuevas animaciones
- Nuevos sprites
- Sistema Soul Reaver
- Nuevas palettes
- Nuevas mecánicas
- Efectos visuales
- Variantes futuras

## Estado actual

🚧 **Proyecto en desarrollo activo.**

Implementado actualmente:

- MUGEN 1.0.
- Stand con espada física.

- Transición con espada → sin espada.
- Transición sin espada → con espada.
- Animación para clavar la espada.
- Animación para recuperarla.
- Helper para representar la espada fuera de Raziel.
- Grieta de aparición, grieta estable y desaparición.
