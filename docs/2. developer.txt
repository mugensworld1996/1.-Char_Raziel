1. ENGINE
===============================================================================

Engine objetivo:

    MUGEN 1.0

El personaje utiliza:

    stcommon=common1.cns

No se utiliza un common1.cns completo personalizado.

Cuando Raziel necesita comportamiento propio en un State común, se sobrescribe
solamente ese State desde los CNS del personaje.

Estados comunes personalizados actualmente relevantes:

    State 0  = Stand
    State 20 = Walk

3. VARIABLES GLOBALES
===============================================================================

var(20) = ESTADO DE LA ESPADA FÍSICA

    0 = equipada / en la mano
    1 = clavada en el suelo
    2 = lanzada / volando
    3 = caída en el suelo

var(21) = REAVER ACTIVO

    0 = Spectral
    1 = Fire
    2 = Air
    3 = Water
    4 = Earth
    5 = Lightning
    6 = Light
    7 = Dark
    8 = Spirit

var(22) = CARGA DE LA ESPADA

    Inicializa en 0.
    La mecánica de carga todavía no está implementada.

Inicialización por round:

    var(20)=0
    var(21)=0
    var(22)=0

Resultado:

    Raziel empieza con la Soul Reaver física equipada.
    Spectral queda preparado como Reaver base para cuando la espada ya no esté
    en la mano.


===============================================================================
4. CORE.CNS
===============================================================================

-------------------------------------------------------------------------------
STATE 0 — STAND
-------------------------------------------------------------------------------

Forma con espada:

    var(20)=0
        -> Action 1000

Forma sin espada:

    var(20)!=0
        -> Action 0

El State conserva lógica estándar relevante:
- Reset de velocidad Y.
- Frenado.
- Cambio a State 5050 al morir.

Giro:
- Action 5 sigue siendo el giro estándar sin espada.
- Action 8 es el giro específico con espada.
- Cuando Raziel tiene la espada, el sistema sustituye visualmente el giro
  estándar por Action 8.


-------------------------------------------------------------------------------
STATE 20 — WALK
-------------------------------------------------------------------------------

Se utiliza un único State 20 para ambas formas.

Velocidades:

    adelante
        Const(velocity.walk.fwd.x)

    atrás
        Const(velocity.walk.back.x)

Con espada:

    holdfwd
        -> Action 1010

    holdback
        -> Action 1015

Sin espada:

    holdfwd
        -> Action 20

    holdback
        -> Action 21

Al dejar de mantener adelante/atrás:

    ChangeState -> 0

La física no se duplica por forma; solamente se selecciona la animación
correspondiente según var(20).


===============================================================================
5. SYSTEM.CNS
===============================================================================

system.cns contiene State -2 y State -3.

-------------------------------------------------------------------------------
GIRO GLOBAL CON ESPADA
-------------------------------------------------------------------------------

Cuando:

    var(20)=0
    Anim=5

el giro normal se sustituye por:

    Action 8

Objetivo:
que Raziel utilice su giro con espada independientemente de si llega al giro
desde Stand, Walk o después de una transición como salto/aterrizaje.


-------------------------------------------------------------------------------
SPECTRAL REAVER
-------------------------------------------------------------------------------

Spectral es:

    var(21)=0

y solamente debe mostrarse cuando:

    var(20)!=0

Es decir:

    sin espada física
    +
    Reaver activo = Spectral

Color según palette:

    PalNo 1 o 3
        -> Spectral azul

    PalNo 2 o 4
        -> Spectral verde

Recursos visuales actuales:

AZUL
    Stand:
        Explod ID 7000
        anim 7000

    Walk:
        Explod ID 7001
        anim 7000

    Crouch:
        Explod ID 7005
        anim 7005

    Stand -> Crouch:
        Explod ID 7006
        anim 7006

    Crouch -> Stand:
        Explod ID 7007
        anim 7007

VERDE
    Stand:
        Explod ID 7100
        anim 7100

    Walk:
        Explod ID 7101
        anim 7100

    Crouch:
        Explod ID 7105
        anim 7105

    Stand -> Crouch:
        Explod ID 7106
        anim 7106

    Crouch -> Stand:
        Explod ID 7107
        anim 7107

IMPORTANTE:
Los IDs 7001 / 7101 identifican los Explods de Walk, pero actualmente reutilizan
las Actions visuales 7000 / 7100 con otra posición.

State -3 conserva el sonido de aterrizaje para:

    State 52
    State 106


===============================================================================
6. CMD — CAMBIO DE ESPADA
===============================================================================

Comando:

    [Command]
    name = "sword_switch"
    command = y+z
    time = 1


-------------------------------------------------------------------------------
CLAVAR ESPADA
-------------------------------------------------------------------------------

Condiciones:

    command = "sword_switch"
    var(20)=0
    statetype=S
    ctrl

Resultado:

    State 2100


-------------------------------------------------------------------------------
RECUPERAR ESPADA
-------------------------------------------------------------------------------

La recuperación ya NO depende solamente de var(20).

Condiciones actuales:

    command = "sword_switch"
    var(20)=1
    statetype=S
    ctrl
    NumHelper(6500) > 0
    Helper(6500), StateNo = 7010
    Abs(Helper(6500), Pos X - Pos X) <= 20

Resultado:

    State 2110

Esto impide recuperar la espada desde cualquier parte del escenario.

La distancia actual usada por el prototipo es:

    20 unidades

7. CMD — CAMBIO DE REAVER
===============================================================================

Cuando Raziel está SIN espada puede cambiar de Reaver con:

    Z

Controlador actual:

    var(21) = ifelse(var(21) >= 8, 0, var(21) + 1)

Condiciones:

    var(20)!=0
    command="z"
    command!="sword_switch"
    statetype=S
    ctrl
    command!="holdfwd"
    command!="holdback"

Ciclo:

    0 Spectral
      ↓
    1 Fire
      ↓
    2 Air
      ↓
    3 Water
      ↓
    4 Earth
      ↓
    5 Lightning
      ↓
    6 Light
      ↓
    7 Dark
      ↓
    8 Spirit
      ↓
    0 Spectral

IMPORTANTE:

conectado. Los demás valores no tienen todavía powers/FX definitivos.

8. SWORD.CNS
===============================================================================

-------------------------------------------------------------------------------
STATE 2100 — CLAVAR
-------------------------------------------------------------------------------

Forma:

    CON ESPADA -> SIN ESPADA

Animación:

    1005

Durante AnimElem 8:

    crea Helper
    ID = 6500
    stateno = 7000
    name = "Physical Soul Reaver"

Al terminar:

    var(20)=1
    ChangeState -> 0


-------------------------------------------------------------------------------
STATE 2110 — RECUPERAR
-------------------------------------------------------------------------------

Forma:

    SIN ESPADA -> CON ESPADA

Animación:

    1006

Al terminar:

    var(20)=0
    ChangeState -> 0

El State 2110 solamente puede iniciarse desde CMD cuando se cumplen las
condiciones de proximidad descritas en la sección anterior.


===============================================================================
9. WEAPON.CNS
===============================================================================

Helper lógico:

    ID = 6500

States:

    7000 = aparición de la grieta
    7010 = espada clavada / estable
    7020 = recuperación
    7030 = grieta residual / desaparición

Explods:

    6501 = aparición de grieta
    6502 = grieta estable
    6503 = desaparición de grieta
    6504 = frente de la grieta
    6505 = espada clavada

Capas:

    6501 / 6502 / 6503
        sprpriority = -5
        -> detrás de los personajes

    6505
        sprpriority = 5
        -> delante de los personajes

    6504
        sprpriority = 6
        -> delante de la espada

Resultado:

    grieta de fondo
        < personajes
            < espada
                < frente de grieta

Esto genera el falso efecto 3D de la espada atravesando el suelo.


-------------------------------------------------------------------------------
STATE 7000
-------------------------------------------------------------------------------

- Crea 6501.
- Crea 6504.
- 6501 usa removetime=-1 para evitar el parpadeo.
- Cuando Root deja State 2100 -> State 7010.


-------------------------------------------------------------------------------
STATE 7010
-------------------------------------------------------------------------------

- Elimina 6501.
- Crea 6502.
- Crea 6505.
- Crea/mantiene 6504.
- Representa la espada realmente clavada.
- Es el State exigido por CMD para permitir recuperación.
- Cuando Root entra a State 2110 -> State 7020.


-------------------------------------------------------------------------------
STATE 7020
-------------------------------------------------------------------------------

- Elimina la espada independiente 6505.
- Mantiene la grieta mientras Raziel reproduce Action 1006.
- Cuando Root deja State 2110 -> State 7030.


-------------------------------------------------------------------------------
STATE 7030
-------------------------------------------------------------------------------

- Elimina 6504.
- Mantiene 6502.
- Time=120:
    elimina 6502
    crea 6503
- Time=180:
    DestroySelf

15. PUNTO DE CONTINUACIÓN
===============================================================================

Siguiente bloque recomendado:

1. Crear Stand -> Crouch con espada.
2. Crear Crouch con espada.
3. Crear Crouch -> Stand con espada.
4. Crear Jump Start / Jump / Fall / Landing con espada.
5. Adaptar Run / Dash con espada.
6. Después comenzar normales y combos propios de espada.
7. Luego ampliar el sistema real de los nueve Reavers.

No rehacer la arquitectura sin una razón concreta.
