# Sistema Soul Reaver

El Soul Reaver funciona mediante:

- Explods persistentes
- ownpal = 1
- overlays independientes
- animaciones separadas por palette

---

# IDs del Soul Reaver

| Palette | IDs |
|---|---|
| Palette 1 | 7000–7007 |
| Palette 2 | 7100–7107 |

---

# Funcionamiento técnico

El sistema utiliza:

```txt
type = Explod
bindtime = -1
ownpal = 1
sprpriority = 4
```

Esto permite:

- mantener el Reaver unido al personaje
- usar palettes independientes
- renderizar encima del sprite principal

---

# Pipeline de sprites

## Proceso general

1. Creación de sprite base
2. Conversión 3D
3. Generación de animación
4. Export a video
5. Extracción de frames
6. Conversión BMP
7. Importación a SFF

| 0–199 | States comunes |
| 200–299 | Normales de pie |

| 600–699 | Normales aéreos |
| 800–899 | Throws |
| 1000–1999 | Specials |
| 3000–3999 | Supers |

# Convenciones futuras

## Specials

Todos los specials deben separarse en:

```txt
logic/raziel_specials.cns
```

---

## FX

Todos los efectos deben separarse en:

```txt
logic/raziel_fx.cns
```

---

## Reaver variants

Cada variante futura del Reaver debe tener:

- palette propia
- anim IDs independientes
- Explods separados

---

# Recomendaciones para contributors

- Mantener nomenclatura consistente
- No reutilizar state IDs existentes
- Mantener palettes indexadas
- Mantener sprites en BMP indexado
- Documentar nuevos systems

---

# Compatibilidad

Proyecto diseñado para:

- MUGEN 1.0

No compatible oficialmente con:

- WinMUGEN
- MUGEN 1.1

---

# Filosofía del proyecto

Este proyecto es completamente libre para:

- estudiar
- modificar
- reutilizar
- expandir

La intención es mantener el espíritu abierto de la comunidad MUGEN.
